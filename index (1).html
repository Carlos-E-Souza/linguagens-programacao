hub.go
func (h *Hub) Run(ctx context.Context) {
    for {
        select {
        case c := <-h.register:
            h.clients[c.userID] = c
        case c := <-h.unregister:
            delete(h.clients, c.userID)
        case m := <-h.incoming:
            h.deliver(m)
        case <-ctx.Done():
            return
        }
    }
}

Chat em Tempo Real com Go e WebSockets

Sistema de mensagens instantâneas para muitos usuários conectados ao mesmo tempo, com conversas individuais (1:1) e em grupo.

O problema que ele ataca é entregar um grande volume de mensagens com baixa latência e pouco consumo de memória e CPU, sem perder nem embaralhar mensagens quando a conexão cai. Cada mensagem recebe um identificador único, é confirmada por um ACK, fica na fila do cliente até ser entregue e segue uma numeração por conversa que garante a ordem de exibição.

Aplicação 1 · back-end

Servidor de mensagens

Cuida de autenticação, usuários, conversas e do roteamento das mensagens em tempo real, além de guardar o histórico. Expõe uma API REST e um endpoint WebSocket autenticado por token JWT.

Cada cliente conectado ganha duas goroutines (leitura e escrita), um Hub central decide para quem entregar, e um worker pool grava no banco sem atrasar a entrega.

Aplicação 2 · front-end

Cliente desktop

Aplicativo de desktop feito com Wails. A camada em Go mantém a conexão, reconecta sozinha, guarda uma fila de mensagens pendentes e um cache local.

A interface, em HTML, CSS e JavaScript puros, mostra conversas, grupos, presença online, o aviso de “digitando…” e o status de cada mensagem: enviada, entregue ou lida.

Recursos de Go explorados

Goroutines

Duas por cliente conectado. Ocupam poucos kilobytes e são escalonadas pelo runtime, não pelo sistema operacional.

Channels

Toda a comunicação entre goroutines passa por eles. Os com buffer absorvem picos e permitem desconectar clientes lentos.

select

O laço central do Hub trata registro, desconexão e envio sem bloquear.

sync.RWMutex

Protege o Hub e permite muitas leituras simultâneas com escritas seguras.

Worker pool

Um conjunto fixo de goroutines grava as mensagens no banco, sem atrasar a entrega em tempo real.

context.Context

Propaga cancelamento e timeouts entre requisições, conexões e workers.

time.Ticker

Envia pings periódicos (heartbeat) para detectar conexões mortas e liberar recursos.

Graceful shutdown

Com WaitGroup e sinais do sistema, mensagens pendentes são gravadas antes de encerrar.

net/http

Servidor HTTP concorrente da biblioteca padrão, sem frameworks externos.
